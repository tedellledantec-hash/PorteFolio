Mise en ligne sur GitHub Pages :
1. Décompresse cette archive.
2. Envoie index.html, style.css, DESIGN.md, README.txt et les dossiers images/ et documents/ à la racine de ton dépôt GitHub (pas le dossier parent).
3. Dans GitHub : Settings > Pages > Deploy from a branch > branche main > dossier / (root) > Save.
