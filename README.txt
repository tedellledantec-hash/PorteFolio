PORTFOLIO BTS SIO SISR — VERSION UNE PAGE

Mise en ligne sur GitHub Pages :
1. Décompresse cette archive.
2. Ouvre le dossier portfolio-one-page.
3. Envoie index.html, style.css, images/ et documents/ à la racine de ton dépôt GitHub (pas le dossier parent).
4. Dans GitHub : Settings > Pages > Deploy from a branch > branche main > dossier / (root) > Save.

À personnaliser avant publication :
- Remplacer tous les textes [À COMPLÉTER], [ANNÉE], [TON-PSEUDO], etc.
- Ajouter CV.pdf dans documents/.
- Ajouter les dossiers PDF/ZIP mentionnés dans les liens dans documents/.
- Vérifier les compétences cochées et les périodes du tableau E5 avec ton tableau officiel.
- Remplacer le lien e-mail et les liens GitHub/LinkedIn.

Les dossiers images/ et documents/ sont prévus pour tes futurs fichiers. Les liens vers les documents n'afficheront rien tant que les fichiers correspondants ne sont pas ajoutés.
